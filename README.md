# AgonOps

Production-style multiplayer game infrastructure on AWS, built around the open-source Space Agon demo.

## Project Goal

AgonOps focuses on the infrastructure behind multiplayer game servers rather than game development itself.

The project will demonstrate:

- AWS
- Terraform
- Amazon EKS
- Kubernetes
- Agones
- Open Match
- Helm
- GitHub Actions CI/CD
- Prometheus & Grafana
- Autoscaling
- Load testing
- Observability
- Cost optimization

## Current Status

### Local environment ✅

- Space Agon running on Kubernetes with Minikube
- Agones GameServer Fleet operational
- Open Match matchmaking operational
- Redis operational
- Dedicated GameServer successfully allocated
- Playable multiplayer workload validated
- Automated local startup and shutdown scripts
